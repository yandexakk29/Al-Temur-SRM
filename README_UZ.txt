AL TEMUR CRM — Android loyiha boshlang‘ich versiyasi

Funksiyalar:
- Mijoz ismi, telefon raqami, qiziqqan katyoli va izohini saqlash
- Saqlash vaqtida sana-vaqtni avtomatik yozish
- Mijoz holatini belgilash
- Qayta qo‘ng‘iroq vaqtini yozish
- Ism yoki telefon bo‘yicha qidirish
- Mijozga telefon qilish uchun terish oynasini ochish
- Ma’lumotlarni telefon ichidagi SQLite bazasida saqlash

Hozircha kiritilmagan:
- Kiruvchi SIM qo‘ng‘iroqlarini avtomatik tutish
- WhatsApp / Telegram / MAX integratsiyasi
- Belgilangan vaqtda haqiqiy bildirishnoma
- Qo‘ng‘iroq audiosini yozish yoki nutqni matnga aylantirish

TELEFON ORQALI APK YIG‘ISH:
1. GitHub hisobiga kiring va New repository yarating.
2. Ushbu loyiha papkasidagi fayllarni repository'ga yuklang (Upload files).
3. Actions bo‘limiga kiring; workflow avtomatik ishga tushadi yoki Run workflow tugmasini bosing.
4. Build tugagach, workflow run sahifasining pastidagi Artifacts bo‘limidan AlTemurCRM-debug-apk ni yuklab oling.
5. ZIP ichidan app-debug.apk ni chiqaring va Android telefoningizga o‘rnating.

Loyiha Android Gradle Plugin 8.7.3, JDK 17 va Android SDK platform 35 uchun tuzilgan.
Bu boshlang‘ich prototip. APK hali qurilmalarda tekshirilmagan. Avtomatik qo‘ng‘iroq va messenjer integratsiyalarini keyingi bosqichda qo‘shish kerak.
